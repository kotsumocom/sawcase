概要

Sawcase は sawtooth-css の上に載るレイアウト CSS + 軽量 JS ライブラリです。 管理画面・ドキュメントページ・LP の骨格をクラスベースで提供します。

インストール

以下のコマンドでインストールできます：

deno add jsr:@kotsumo/sawcase

基本的な使い方

sawcase を使うには、まず CSS と JS を生成します。 generate.ts を使って dev.ts に組み込むのが推奨です。 

import { generateSawcaseCSS } from "@kotsumo/sawcase/generate";

await generateSawcaseCSS({
  output: "./static/sawcase.css",
  jsOutput: "./static/sawcase.js",
  sawtooth: { output: "./static/sawtooth.css" },
  theme: { colors: { primary: "#6750A4" } },
});

プレフィックス体系

sawcase のクラスは以下のプレフィックスで分類されます：

プレフィックス 用途
sc-admin- 管理画面
sc-docs- ドキュメント
sc-lp- LP [β]
sc- 共通

Note: コンポーネント（ボタン、入力等）は sawtooth-css の st-* クラスを使います。
